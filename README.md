## Topic 1: Web Architecture & Core DAW Terminology

### 1. Key Technical Terms (Vocabulario Clave)

| Term (Término) | Pronunciation | Definition & Use |
| :--- | :--- | :--- |
| **Frontend** | `/frʌnt-end/` | The client-side of an application (what the user sees). *Example: "We built the frontend using React."* |
| **Backend** | `/bæk-end/` | The server-side logic and database interactions. *Example: "The backend is handled by Node.js."* |
| **Database (DB)** | `/deɪtə-beɪs/` | Structured collection of data. *Example: "We need to query the SQL database."* |
| **Deploy** | `/dɪˈplɔɪ/` | To publish or launch an application to a production server. *Example: "We will deploy the web app tonight."* |
| **Framework** | `/freɪm-wɜːrk/` | A platform/structure for building software applications. *Example: "Laravel is a popular PHP framework."* |

---

### 2. Useful Work Expressions (Expresiones Útiles)

- **"To build an application"** $\rightarrow$ Desarrollar/construir una aplicación.
- **"To fix a bug"** $\rightarrow$ Corregir un error de código.
- **"To handle data"** $\rightarrow$ Gestionar / procesar datos.
- **"Client-side vs. Server-side"** $\rightarrow$ Lado del cliente (navegador) vs. Lado del servidor.

### 4. Client-Server Architecture & HTTP Basics (Conceptos Clave de Redes)

Cuando hablas de desarrollo web en inglés, estas son las acciones clave que ocurren entre el navegador y el servidor:

| Verb / Concept | Translation | Example in Context |
| :--- | :--- | :--- |
| **Request (n/v)** | Petición / Pedir | *"The browser sends an HTTP request to the server."* |
| **Response (n)** | Respuesta | *"The server sends back a 200 OK response."* |
| **Fetch (v)** | Obtener / Traer datos | *"We need to fetch the user profile from the API."* |
| **Endpoint (n)** | Punto de acceso (URL) | *"This API endpoint returns a JSON object."* |
