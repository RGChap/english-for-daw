Esta guía reúne las reglas gramaticales clave del inglés técnico para que consultes rápidamente cómo construir tus frases sin dudas.

---

## 📌 1. Regla de Oro: Preposición + Verbo en `-ING`

En inglés, si después de una preposición va un **verbo**, ese verbo **SIEMPRE** lleva la terminación **`-ing`**. Nunca se usa el infinitivo normal (*send*, *log*) ni con *to* (*to send*).

| Preposición | Regla | Ejemplo en Inglés | Traducción al Español |
| :--- | :--- | :--- | :--- |
| **Before** (Antes de) | `Before` + **-ing** | *Before **sending** the data* | Antes de **enviar** los datos |
| **After** (Después de) | `After` + **-ing** | *After **logging** in* | Después de **iniciar** sesión |
| **Without** (Sin) | `Without` + **-ing** | *Without **updating** the view* | Sin **actualizar** la vista |
| **By** (Mediante / Para) | `By` + **-ing** | *By **fixing** the bug* | Corrigiendo / Al **corregir** el fallo |

## 📌 2. Las Preposiciones Clave en Programación

### A) Ubicación y Estado (`IN`, `ON`, `AT`)

* **`IN` (Dentro de un archivo, base de datos o sistema):**
  * *In the database* (En la base de datos)
  * *In the file / code* (En el archivo / código)
  * *In the array / table* (En la matriz / tabla)
* **`ON` (En una superficie, pantalla, servidor o red):**
  * *On the page / view* (En la página / vista)
  * *On the server / cloud* (En el servidor / la nube)
  * *On GitHub / the web* (En GitHub / la web)
* **`AT` (En un punto exacto o línea):**
  * *At the endpoint* (En el punto de acceso)
  * *At line 42* (En la línea 42)

### B) Origen y Destino (`TO` vs `FROM`)

* **`TO` (Dirección hacia un destino):**
  * *Send a request **to** the server* (Enviar una petición al servidor)
  * *Push changes **to** GitHub* (Subir cambios a GitHub)
  * *Log in **to** the app* (Iniciar sesión en la app)
* **`FROM` (Origen de los datos):**
  * *Fetch data **from** the API* (Obtener datos de la API)
  * *Data **from** the database* (Datos de la base de datos)

## 📌 3. Los Adjetivos van DELANTE del Sustantivo

En inglés, la cualidad (adjetivo) se coloca **antes** del objeto que describe. No traducimos "de forma [adjetivo]".

* ❌ **Incorrecto:** *The component responsive* / *The component in a responsive way*
* ✅ **Correcto:** *The **responsive** component* (El componente adaptable)
* ✅ **Correcto:** *The **invalid** token* (El token inválido)
* ✅ **Correcto:** *A **fast** query* (Una consulta rápida)

## 📌 4. Uso de Artículos (`A`, `AN`, `THE` y Omisión)

### A) `A` vs `AN` (Un / Una)
* Usa **`a`** delante de sonido de consonante: *a bug*, *a branch*, *a server*.
* Usa **`an`** delante de sonido de vocal: *an issue*, *an API*, *an endpoint*, *an invalid token*.

### B) Cuándo NO usar `THE` (El / La / Los / Las)
No se usa *the* cuando hablamos de conceptos abstractos, generales o permisos técnicos:

* ❌ *The server denied the access*  
  👉 ✅ *The server denied **access**.* (Denegó el acceso)
* ❌ *The admin granted the permission*  
  👉 ✅ *The admin granted **permission**.* (Concedió el permiso)

---

## 📌 5. Sustantivos Incontables

Algunas palabras en inglés no se pueden contar individualmente y **nunca llevan "s" al final**:

* **`Data`** (Datos): Se usa como un bloque único.
  * ❌ *The datas are loaded*  
  👉 ✅ *The **data** is loaded.*
