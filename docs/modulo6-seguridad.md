# 🛡️ Módulo 6: Autenticación, Seguridad y Permisos

[← Volver al Índice Principal](../README.md)

En este módulo aprenderás el vocabulario esencial para gestionar sesiones de usuario, encriptación, roles de acceso y la comunicación segura entre cliente y servidor.

---

## 🔑 Vocabulario Clave

| Término (Inglés) | Traducción al Español | Notas de Uso Técnico |
| :--- | :--- | :--- |
| **Authentication** | Autenticación | Proceso de verificar **quién es** el usuario. |
| **Authorization** | Autorización | Proceso de verificar **qué puede hacer** el usuario. |
| **Credentials** | Credenciales | Usuario y contraseña (o token) para acceder. |
| **Password** | Contraseña | Sustantivo. (*Encrypted password*). |
| **Token** | Token / Clave de acceso | Cadena cifrada para peticiones (*JWT Token*). |
| **Session** | Sesión | Periodo de tiempo que el usuario está identificado. |
| **Permission** | Permiso | Acción específica permitida (lectura, escritura). |
| **Role** | Rol | Perfil de usuario (*Admin*, *User*, *Guest*). |
| **Access** | Acceso | Sustantivo (*Grant/Deny access*). |

## ⚡ Verbos Principales (Presente y Pasado)

| Verbo (Presente) | Verbo (Pasado / Participio) | Traducción | Ejemplo de Uso |
| :--- | :--- | :--- | :--- |
| **To log in** | Logged in | Iniciar sesión | *The user logged in.* |
| **To log out** | Logged out | Cerrar sesión | *She logged out of the app.* |
| **To authenticate** | Authenticated | Autenticar | *The server authenticated the user.* |
| **To authorize** | Authorized | Autorizar | *The system authorized the request.* |
| **To encrypt** | Encrypted | Encriptar / Cifrar | *We encrypted the password.* |
| **To grant** | Granted | Conceder / Dar | *The admin granted the permission.* |
| **To deny** | Denied | Denegar / Rechazar | *The server denied the access.* |

---

## 💡 Dificultades Clave y Matices de Seguridad

* **Authentication vs. Authorization:**
  * **`Authentication`**: Responde a la pregunta *"¿Quién eres?"* (identificación).
  * **`Authorization`**: Responde a la pregunta *"¿Tienes permiso para hacer esto?"* (permisos).
* **Phrasal Verbs (Log in / Log out):**
  * Se escriben **separados** cuando funcionan como verbo: *I want to log in*.
  * Se escriben **juntos** solo si son sustantivos o adjetivos: *The login button*.
* **To Grant vs. To Deny:**
  * **`Grant`**: Se usa para dar o conceder acceso/permisos (*grant access*).
  * **`Deny`**: Se usa para rechazar o denegar acceso (*access denied*).
