## 📖 Vocabulario Técnico Clave
- **Branch:** Rama
- **Commit:** Confirmar / Guardar cambios
- **Push:** Subir cambios al servidor remoto
- **Pull:** Traer / Descargar cambios del servidor remoto
- **Merge:** Fusionar / Unir ramas
- **Merge Conflict:** Conflicto de fusión
- **Bug / Issue:** Error / Problema
- **Fix / Fixed:** Arreglar / Arreglado
