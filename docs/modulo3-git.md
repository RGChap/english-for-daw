---

## 📖 Vocabulario Técnico Clave
- **Branch:** Rama
- **Commit / Committed:** Confirmar cambios / Confirmó cambios
- **Push / Pushed:** Subir cambios / Subió cambios
- **Pull / Pulled:** Traer cambios / Trajo cambios
- **Merge / Merged:** Fusionar / Fusionó
- **Merge Conflict:** Conflicto de fusión
- **Bug / Issue:** Error / Problema o Incidencia
- **Fix / Fixed:** Arreglar / Arreglado
- **Team:** Equipo (de personas)

---

## 📝 Práctica Interactiva (10 Ejercicios)

1. **"Creé una nueva rama."**  
   👉 `I created a new branch.`

2. **"El desarrollador arregló el bug."**  
   👉 `The developer fixed the bug.`

3. **"Tengo un conflicto de fusión."**  
   👉 `I have a merge conflict.`

4. **"Ella subió los cambios."**  
   👉 `She pushed the changes.`

5. **"El servidor tiene un bug."**  
   👉 `The server has a bug.`

6. **"Fusionamos la rama."**  
   👉 `We merged the branch.`

7. **"El equipo solucionó el problema."**  
   👉 `The team fixed the issue.`

8. **"Traje los últimos cambios."**  
   👉 `I pulled the latest changes.`

9. **"La API tiene un problema."**  
   👉 `The API has an issue.`

10. **"Él confirmó los cambios."**  
   👉 `He committed the changes.`
