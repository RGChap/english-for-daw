## 📖 Vocabulario Técnico Clave
- **Request:** Petición / Solicitud
- **Response:** Respuesta
- **Timeout / Timed out:** Tiempo de espera agotado / Se agotó el tiempo
- **High latency:** Latencia alta / Retardo elevado
- **Bandwidth:** Ancho de banda
- **To send / Sent / Sending:** Enviar / Envió / Enviando
- **To receive / Received / Receiving:** Recibir / Recibió / Recibiendo
- **To answer / Answered:** Responder / Respondió

---

## 📝 Práctica Interactiva (10 Ejercicios)

#### 1. Notificar tiempo de espera agotado
- **Español:** *"La petición agotó el tiempo de espera."*
- **Inglés:** The request timed out.

#### 2. Reportar latencia alta
- **Español:** *"El servidor tiene latencia alta."*
- **Inglés:** The server has high latency.

#### 3. Indicar envío de respuesta
- **Español:** *"La API está enviando la respuesta."*
- **Inglés:** The API is sending the response.

#### 4. Notificar consumo de ancho de banda
- **Español:** *"La base de datos consume mucho ancho de banda."*
- **Inglés:** The database consumes a lot of bandwidth.

#### 5. Confirmar recepción de petición
- **Español:** *"El servidor recibió la petición."*
- **Inglés:** The server received the request.

#### 6. Notificar lentitud en respuesta
- **Español:** *"La respuesta es muy lenta."*
- **Inglés:** The response is very slow.

#### 7. Indicar proceso activo de recepción
- **Español:** *"La API está recibiendo la petición."*
- **Inglés:** The API is receiving the request.

#### 8. Notificar fallo de respuesta
- **Español:** *"La base de datos no envió la respuesta."*
- **Inglés:** The database didn't send the response.

#### 9. Plural con latencia alta
- **Español:** *"El servidor y la API tienen latencia alta."*
- **Inglés:** The server and the API have high latency.

#### 10. Confirmar tiempo de espera superado en base de datos
- **Español:** *"La base de datos agotó el tiempo de espera."*
- **Inglés:** The database timed out.
